## Projects

### Guardrail API
An API-key based protection layer designed to defend endpoints against data scraping and automated extraction attacks. The project focuses on request pattern analysis and access control to reduce exposure to bulk scraping attempts.

### Security Research Bot
An in-progress project exploring bot behavior, automated request handling, and how modern security systems detect and respond to automated traffic. The goal is to understand defensive mechanisms from the ground up while building practical scripting and automation skills.
