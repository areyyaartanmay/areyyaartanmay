## About Me

I am a Class XII student building a strong foundation in computer science through consistent, hands-on practice rather than shortcuts. My current focus is data structures and algorithms alongside web development, since both are high-demand skills that compound well together.

Outside of coursework, I build small independent projects to apply what I learn — most recently around API protection and understanding how security systems detect and respond to automated traffic. I make heavy use of AI-assisted development to move quickly, but I always go back and study the underlying logic so I actually understand what I ship, not just what runs.
